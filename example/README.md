# Example App - ublue-hero-react

This is an example React app demonstrating the `ublue-hero-react` component.

## Running

```bash
npm install
npm run dev
```

## About

This app uses a local development setup with `--save-peer` to link to the parent library:

```bash
npm install --save-peer ../
```

## Features Demonstrated

- Basic component usage
- Custom particle count
- Different noise scales
- Accessibility settings
